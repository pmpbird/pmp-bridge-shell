PMP Notes Backend Bridge v1

No-money private memory bridge. App shell stays public. Private memory goes to your iPhone Notes through Shortcuts.

Route: PMP app → clipboard / share → Apple Shortcut → Notes. The app cannot secretly read or write Notes directly. You control the handoff.

Shortcut Setup

Create a Shortcut named: PMP Save Private Memory Shortcut actions: 1. Get Clipboard or use Shortcut Input. 2. Add date/time if you want. 3. Append the text to the note named: PMP Private Bug Memory If iOS uses slightly different wording, choose the Notes action that appends received text to that note.
