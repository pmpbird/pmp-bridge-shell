This pass looks for testing blind spots, oracle failure, flaky tests, nondeterminism, coverage illusion, contaminated test data, mutation gaps, integration mismatch, and proof-chain failure.

## Provisional records

### TEST-001 — The test oracle is wrong

A test may compare against an incorrect expected result, outdated requirement, mistaken fixture, or misunderstood behavior.

HARM: correct behavior fails or unsafe behavior passes.

OVERLAP TO CHECK: PROOF-001, GOV-007.

### TEST-002 — The oracle is derived from the implementation under test

Expected values may be generated by the same logic, helper, model, or transformation being tested.

HARM: the implementation confirms itself without independent truth.

OVERLAP TO CHECK: MEM-003, AUD-004.

### TEST-003 — Assertions are too weak

Tests may check only that a page loads, a value exists, no exception occurred, or a status is truthy.

HARM: semantically wrong or incomplete behavior passes.

OVERLAP TO CHECK: QUAL-002, PROOF-003.

### TEST-004 — Negative and forbidden behavior are not tested

The suite may verify what should happen without testing what must never happen.

HARM: authority leaks, data loss, unsafe promotion, or silent fallback remain undetected.

OVERLAP TO CHECK: RUN-015, PROOF-005.

### TEST-005 — Boundary values and empty states are missing

Zero, one, maximum, just-over-maximum, empty, null, duplicate, and malformed cases may be absent.

HARM: ordinary edge conditions fail in production.

OVERLAP TO CHECK: SEM-002, SCHEMA-005.

### TEST-006 — Tests pass without executing the intended path

Wrong imports, stale bundles, feature flags, mocks, skipped setup, dead code, or alternate routes may prevent the target logic from running.

HARM: a green result proves nothing about the changed behavior.

OVERLAP TO CHECK: REPO-004, BUILD-004.

### TEST-007 — Skipped, quarantined, or expected-failure tests are hidden

Skipped tests, xfail markers, ignored suites, filtered tags, or disabled workflows may not be visible in the final summary.

HARM: known failures disappear inside an apparently complete PASS.

OVERLAP TO CHECK: AUD-003, MEAS-001.

### TEST-008 — Test order changes results

Shared state, caches, globals, timing, or incomplete cleanup may make a test pass or fail depending on sequence.

HARM: isolated runs and full-suite runs disagree.

OVERLAP TO CHECK: REL-006, TEST-031.

### TEST-009 — Repeated retries mask flakiness

A test runner may automatically rerun failures and report only the successful attempt.

HARM: intermittent defects are converted into PASS.

OVERLAP TO CHECK: REL-008, OBS-003.

### TEST-010 — Randomness is uncontrolled or overcontrolled

Unrecorded random seeds make failures irreproducible, while one fixed seed hides large parts of the state space.

HARM: rare defects are missed or cannot be reproduced.

OVERLAP TO CHECK: CRYPTO-005, TEST-014.

### TEST-011 — Time-dependent tests are unstable

Wall clock, time zone, daylight saving, expiry, animation, debounce, and scheduled jobs may change outcomes.

HARM: tests fail unpredictably or never exercise real timing conditions.

OVERLAP TO CHECK: REL-007, LOC-001.

### TEST-012 — Concurrency and race conditions are not exercised

Tests may run serially even though tabs, devices, workers, callbacks, retries, and network responses can overlap.

HARM: lost updates and split states appear only in real use.

OVERLAP TO CHECK: REL-006, REL-002.

### TEST-013 — Network failure shapes are oversimplified

Tests may cover success and total failure but not delay, duplication, reordering, partial response, disconnect, ambiguous timeout, or recovery.

HARM: real network incidents produce unsafe retries or mixed state.

OVERLAP TO CHECK: NET-001, REL-003.

### TEST-014 — Property-based and generated tests miss invalid generators

A generator may produce easy, biased, or structurally valid inputs while excluding the dangerous cases.

HARM: large test counts create false breadth.

OVERLAP TO CHECK: MEAS-001, PERF-003.

### TEST-015 — Snapshot tests approve unintended drift

Large snapshots may be updated automatically or reviewed superficially.

HARM: accidental UI, data, permission, or message changes become the new expected result.

OVERLAP TO CHECK: INS-003, AUD-003.

### TEST-016 — Golden files become stale authority

Saved expected outputs may outlive the requirements, provider behavior, or schema that created them.

HARM: obsolete behavior is preserved because the fixture says so.

OVERLAP TO CHECK: GOV-009, PROV-001.

### TEST-017 — Mocks do not match real providers

Mocks may omit latency, failures, limits, malformed output, authentication, retention, and semantic drift.

HARM: integration passes while the live provider fails.

OVERLAP TO CHECK: PROV-001, MEAS-002.

### TEST-018 — Stubbed authority and permissions hide real denial paths

Tests may run with broad local permissions or bypass authentication and approval checks.

HARM: production either fails closed unexpectedly or grants access incorrectly.

OVERLAP TO CHECK: AUTH-004, RUN-015.

### TEST-019 — Test data is contaminated by prior runs

Caches, local storage, databases, queues, branches, fixtures, and provider state may survive between runs.

HARM: a test passes because required state already existed.

OVERLAP TO CHECK: TEST-008, REL-012.

### TEST-020 — Production or private data leaks into testing

Real prompts, source, credentials, user records, or provider outputs may be copied into fixtures, logs, or screenshots.

HARM: testing creates a new privacy and retention breach.

OVERLAP TO CHECK: SEC-006, MIN-003.

### TEST-021 — Synthetic data is not representative

Clean, small, English-only, recent, and internally consistent fixtures may not resemble real historical project data.

HARM: migration, search, rendering, and recovery fail on actual records.

OVERLAP TO CHECK: MIG-007, MEAS-002.

### TEST-022 — Test fixtures encode the same mistaken assumption as the code

Requirements, fixture builders, and implementation may all derive from one flawed interpretation.

HARM: broad test coverage validates the wrong product.

OVERLAP TO CHECK: TEST-002, INTENT-001.

### COV-001 — Line coverage is mistaken for behavioral coverage

Executing a line does not prove all branches, states, effects, or meanings were validated.

HARM: high coverage percentage hides critical gaps.

OVERLAP TO CHECK: MEAS-001, PROOF-003.

### COV-002 — Unreachable or dead code inflates or distorts coverage

Generated code, disabled paths, fallback branches, or obsolete files may remain in reports.

HARM: coverage numbers do not describe the live system.

OVERLAP TO CHECK: TEST-006, REPO-004.

### COV-003 — Cross-file and cross-system behavior is not represented

Unit coverage may be high while storage, routing, provider, Notes, Shortcut, GitHub, and deployment interactions remain untested.

HARM: failures occur at boundaries that no single unit owns.

OVERLAP TO CHECK: OBS-002, TEST-017.

### COV-004 — Requirement and Packet 1.5 coverage are not traced to tests

A suite may have many tests without proving each requirement, limitation, watch, and forbidden behavior is covered.

HARM: important obligations remain testless.

OVERLAP TO CHECK: REG-006, TEST-004.

### MUT-001 — Mutation testing is absent

Tests may never be checked against deliberately introduced faults.

HARM: assertions that cannot detect wrong behavior remain trusted.

OVERLAP TO CHECK: TEST-003, COV-001.

### MUT-002 — Mutations target syntax but not real failure modes

Simple operator changes may be tested while authority, migration, race, rollback, provider, and semantic faults are ignored.

HARM: mutation score overstates meaningful test strength.

OVERLAP TO CHECK: PROOF-005, TEST-012.

### ENV-001 — Test environment differs from deployed environment

Browser engine, iOS version, service worker, origin, HTTPS, file layout, headers, storage, and provider configuration may differ.

HARM: passing tests do not describe the live app.

OVERLAP TO CHECK: PLAT-001, REPO-004.

### ENV-002 — Warm cache hides cold-start failures

Tests may begin after assets, sessions, schemas, permissions, and provider connections are already prepared.

HARM: first-run and recovery paths remain broken.

OVERLAP TO CHECK: MEAS-002, PERF-005.

### ENV-003 — Permission states are not varied

Granted, denied, revoked, limited, expired, and changed permissions may not all be tested.

HARM: the app fails or misrepresents capability after permission changes.

OVERLAP TO CHECK: AUTH-003, PLAT-003.

### ENV-004 — Real-device and Home Screen behavior is replaced by desktop simulation

Responsive browser tests may not reproduce iOS suspension, storage eviction, standalone display, keyboard, viewport, sharing, and Shortcuts behavior.

HARM: the primary target environment remains unproven.

OVERLAP TO CHECK: PERF-006, PLAT-001.

### ENV-005 — Upgrade, downgrade, reinstall, and restore paths are omitted

Tests may validate fresh installation only.

HARM: existing users lose state or become trapped during lifecycle changes.

OVERLAP TO CHECK: MIG-004, PHY-004.

### ENV-006 — Long-run resource and state drift is untested

Short test runs may miss memory leaks, queue accumulation, log growth, token expiry, cache drift, and provider changes.

HARM: the system degrades after hours, days, or months.

OVERLAP TO CHECK: PERF-002, OBS-003.

### PROOFCHAIN-001 — Evidence is not bound to the exact tested artifact

Logs, screenshots, test output, and receipts may omit commit, digest, candidate, configuration, provider, or schema identity.

HARM: valid evidence can be reused for different content.

OVERLAP TO CHECK: REPO-002, DATA-012.

### PROOFCHAIN-002 — Test output can be edited before receipt creation

Console logs, JSON summaries, screenshots, and reports may be manually altered or selectively copied.

HARM: the final proof package no longer reflects execution.

OVERLAP TO CHECK: AUD-001, AUD-003.

### PROOFCHAIN-003 — Stale evidence is reused after mutation

Code, configuration, prompt, model, data, dependency, or environment may change after a passing run.

HARM: the current system inherits proof from an older identity.

OVERLAP TO CHECK: SELF-004, PROOF-012.

### PROOFCHAIN-004 — A manifest lists evidence that is missing or unreadable

Artifact names may exist in a manifest while files are absent, corrupted, private, expired, or inaccessible.

HARM: formal completeness hides practical evidence loss.

OVERLAP TO CHECK: OBS-005, AUD-004.

### PROOFCHAIN-005 — Partial test execution is summarized as full-suite PASS

A timeout, crash, shard failure, filter, pagination issue, or early exit may omit tests while the overall command succeeds.

HARM: incomplete execution receives complete status.

OVERLAP TO CHECK: TOOL-002, TEST-007.

### PROOFCHAIN-006 — Test infrastructure is compromised or misconfigured

Runner images, actions, dependencies, scripts, clocks, secrets, caches, and reporting code may alter results.

HARM: every test can appear green under a broken measuring system.

OVERLAP TO CHECK: BUILD-009, EVAL-001.

### PROOFCHAIN-007 — Independent validation uses the same fixtures and assumptions

A separate reviewer may rerun the same suite with the same oracle, mocks, and omissions.

HARM: repetition is mistaken for independent evidence.

OVERLAP TO CHECK: AGENT-001, TEST-022.

### PROOFCHAIN-008 — Reproduction instructions are incomplete

Evidence may omit exact commands, versions, environment, seeds, permissions, data, and setup.

HARM: another reviewer cannot reproduce or challenge the result.

OVERLAP TO CHECK: MAINT-003, TEST-010.

### PROOFCHAIN-009 — Missing evidence is treated as non-applicable instead of failed

An absent screenshot, log, test, receipt, or comparison may be silently omitted from the gate.

HARM: proof gaps become PASS by default.

OVERLAP TO CHECK: AIH-006, AUD-003.

### PROOFCHAIN-010 — Test suite cost causes selective execution

Slow, flaky, expensive, or complicated tests may be skipped during ordinary changes.

HARM: the strongest protections exist only on paper.

OVERLAP TO CHECK: ECO-004, MAINT-001.
