## Decision

The Universal Active Work Card is part of Packet 01 — Master Builder Guide.

Packet 01 now has two zones:

1. **Permanent Master Guide** — locked except by approved amendment.
2. **Universal Active Work Card** — the only live editable section inside Packet 01.

The card is packet-neutral and must work at Packet 04, Packet 20, or any later authorized packet.

## Current-state precedence

Any old printed `CURRENT AUTHORIZED NEXT PACKET` text inside the original Packet 01 body is historical baseline text.

For current work, use this order:

1. Master Status Ledger
2. current Universal Active Work Card
3. previous completion receipt
4. current packet note

The Active Work Card may update current status and next action, but it may not weaken Packet 01 laws or override a valid completion receipt.

## New-chat startup set

Paste, in order:

1. Packet 00 — Project Start Card
2. Packet 01 — Master Builder Guide, including its current Universal Active Work Card
3. previous packet completion receipt
4. current packet note

No separate Active Work Card note is required.

## Update law

Only the Universal Active Work Card section is updated during normal packet work.

Do not rewrite the permanent Master Guide, Packet 00, completed packets, or old receipts.

Update the card after every important completed step and before changing chats.

When a packet passes:

1. print its completion receipt
2. update the Master Status Ledger
3. replace the card contents with the next authorized packet's starting state
