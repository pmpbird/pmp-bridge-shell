# Whole App Health Layout Trace

1. Open Diagnostics.
2. Tap **Whole App Health Layout Trace**.
3. Immediately open Whole App Health and let the white-card transition occur.
4. After the button changes to **Copy Whole App Health Layout Trace**, tap it and paste the JSON report.

The trace is read-only. It samples computed layout, element rectangles, viewport state, fonts, stylesheet-related mutations, and resize events for five seconds. It does not repair or restyle the app.
