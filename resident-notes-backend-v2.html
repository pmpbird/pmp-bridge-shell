What this tool does

Apple Notes becomes your private memory place. This tool reads the bug ZIP locally, builds private memory chunks, copies each chunk to the clipboard, then opens your Shortcut so the chunk can be appended to a note on your iPhone.

Privacy rule: this tool does not upload Bug Memory to GitHub. It does not show private server details. It only prepares data for your own Notes/Shortcuts bridge.
